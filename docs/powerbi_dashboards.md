# Power BI dashboards

The Power BI assets are preserved in `bi/powerbi/pulsegrid_retail_report_unpacked/`. The folder contains the extracted report package files (`DataModel`, `Report`, metadata, and settings); the original workspace did not contain a single `.pbix` file.

The source planning notes propose these dashboard areas:

1. Executive summary
2. Sales trends
3. Product performance
4. Customer analytics
5. Regional sales
6. Monthly and seasonal sales
7. Customer behavior
8. Profit and revenue
9. Inventory risk
10. Orders and transactions
11. Advanced analytics
12. Interactive filters

The enhanced dashboard table is available at `data/processed/pulsegrid_retail_enhanced_dataset.csv`. It is an aggregated, feature-enriched table; use the transaction-level source data for analyses that require individual orders.
